SmallDocs generates websites. Choose a theme below, run its install command in your site folder, and set theme: in _smalldocs.yml. To customize the result, use your own stylesheet. You do not need to edit the theme's foundation file.

Title labels are optional. Current Folio, Atelier, and Nocturne styles use your page title without a fixed label. The recipes below restore the small labels from the earlier designs.

Release history: the fixed v0.2.0 release and the preserved original snapshots still include those labels. To use the styles without fixed labels, install the current default branch with the commands below. Add --force when replacing an installed copy.

Use the theme's named design settings

Each theme's foundation file names its design settings. The source of those settings is src/foundations.json in each theme repository. An identical foundations.json ships in the installed extension.

A swatch is a named color value. A semantic role assigns a color to a use, such as text or actions. The file also defines light and dark modes, available font weights, type sizes, spacing, and shape. Profiles group settings for documents and for presentations.

To develop a theme, edit the source and rebuild it. Do not edit generated CSS or compatibility aliases by hand. Compatibility aliases are older variable names kept so existing styles still work.

The reference root is the base text size used to calculate relative sizes. Here it is 16px. Generated sizes use rem units, which are multiples of that root and follow browser text preferences. In the reading profile for documents, titles are 36px, section headings are 30px, and the optional display size is 48px. Code and controls have their own named roles.

Applications can use the separate sizes in the presentation profile. Those sizes do not enlarge document navigation.

Type sizes and spacing steps

The foundation type scale is 12, 14, 16, 18, 20, 24, 30, 36, 48, 60, 72. Profiles assign selected steps to prose, interface text, metadata, code, and headings. The three custom themes expose every step as a CSS variable, such as --f-size-20: 1.25rem, alongside variables for reading roles.

Tufte and the Reading themes generate named variables for roles from the same settings, such as --r-size-body and --r-size-ui. To change these generated values, edit the foundation file and rebuild the source.

The spacing scale is 0, 4, 8, 12, 16, 24, 32, 48, 64, 96, 128. It sets gaps for related items, paragraphs, groups, panels, and page gutters. Earlier October CSS combined Bootstrap defaults with individual rem, clamp, and heading overrides. The November foundation files define the shared steps and the reading and presentation profiles explicitly.

Choose the spacing between prose lines

Leading is the distance between lines relative to the text size. The current prose leading of 1.60 is more open than Butterick's preferred range of 1.20 to 1.45. The fixed typography scorecard records that deduction. If your document reads better with tighter line spacing, put this optional override in your own stylesheet. Inspect both modes:

html:root, html.quarto-dark:root {
  --f-line-reading: 1.45;  /* Folio, Atelier, Nocturne */
  --r-line-reading: 1.45;  /* Reading themes */
  --tf-line-reading: 1.45; /* Tufte */
}

The override changes prose leading and keeps code and control sizes. It is a local variation from the audited defaults. After you apply it, check your actual pages in both modes and at a narrow screen width.

Check the rendered component

The palette settings specify contrast targets of 5:1 for ordinary text, 4.5:1 for action text, and 3:1 for meaningful boundaries. They do not override every possible Bootstrap selector.

The 11 November follow-up repairs the dark secondary action in Pulse Reading, the selected navigation pill in Litera Reading, and weak light syntax colors in Darkly Reading. Prose leading remains 1.60. Read the before/after measurements and remaining scope limits.

Use state words and icons, native disabled behavior, aria-current or aria-selected, and associated error text as appropriate. Color alone does not supply those semantics.

Quarto formats

Replace NAME with the theme ID. Install with quarto add rahuldave/smalldocs-NAME. Choose format: NAME-html. Reading overlays compile with Quarto's native Bootswatch base and separate font resources. They do not inject the complete SmallDocs Bootstrap bundle into Quarto. Source repositories include fresh test sites and build instructions.

Your own stylesheet

Keep custom rules in a file named styles.css in your site folder. SmallDocs loads that file after the theme. Theme updates can then replace _extensions/ without replacing your rules.

In _smalldocs.yml, add the stylesheet beside the theme setting:

theme: atelier
css: styles.css

If you already have stylesheets in css:, add styles.css to that list. In a _quarto.yml built by SmallDocs, put css: under format.html. Put theme: under smalldocs::

format:
  html:
    css: styles.css
smalldocs:
  theme: atelier

For Quarto itself, add the file to the custom format. Replace atelier-html with folio-html or nocturne-html for those themes:

format:
  atelier-html:
    toc: true
    css: styles.css

Each label recipe adds decorative text above every page title. Change the quoted text to suit your site. Remove the rule to turn the effect off.

For information that changes with the page, use page content or a subtitle:. Set the subtitle in front matter, the settings at the top of the source file. A subtitle appears below the title as page text. Keep essential information out of CSS-generated labels.

Folio

Folio uses cream paper and forest green in light mode, with deep green and warm pale text in dark mode. Prose and ordinary headings use Source Serif 4. The optional 48px display role uses Libre Caslon Display. Navigation uses DM Sans, and code uses IBM Plex Mono.

Configuration: folio. Light and dark modes. SmallDocs and Quarto. Fonts are bundled locally.

smalldocs add rahuldave/smalldocs-folio
theme: folio

The reading refinement uses a 640px prose column and 1.60 line spacing, with 16px code. Folio keeps a fine rule beneath the title block.

Add the optional "Field notes" label

Add this rule to styles.css after you connect your stylesheet. It uses Folio's secondary color in each mode.

html .quarto-title::before {
  content: "FIELD NOTES / SMALLDOCS";
  display: block;
  font: 500 .6rem var(--bs-font-sans-serif);
  letter-spacing: .16em;
  color: var(--e-secondary);
  margin-bottom: 1.3rem;
}

Atelier

The Reading themes

Each Reading extension includes light and dark modes. The original Bootswatch palette keeps its main colors, and we designed the companion palette. The prose measure is the width of its reading column. It is 640px, with prose leading of 1.60. Code uses local IBM Plex Mono at 16px.

State colors have their own roles. A brand accent is not automatically an error color.

Install an extension with its repository name. Then set the shorter name in theme:. All nine themes that we maintain support SmallDocs and Quarto. Their foundation files define reading and presentation profiles. The document styles use the reading profile.

Pair light and dark themes

All nine themes that we maintain include both modes under one configuration name. SmallDocs shows a mode toggle on a site with a navbar or sidebar.

For Litera Reading alone, use theme: litera-reading to get its complete pair. You can also choose different themes for each mode. For example, install Litera Reading and Darkly Reading:

smalldocs add rahuldave/smalldocs-litera-reading
smalldocs add rahuldave/smalldocs-darkly-reading
theme:
  light: litera-reading
  dark: darkly-reading

On the first visit, SmallDocs uses the browser's color preference. The mode toggle saves the reader's choice. The ?mode=light and ?mode=dark controls in the gallery are preview tools.

Tufte

Tufte was the starting point for this collection. It uses ET Book, cream paper, italic headings, and a narrow reading column. The extension includes light and dark modes for SmallDocs and Quarto.

smalldocs add rahuldave/smalldocs-tufte
theme: tufte
reference-location: margin

reference-location: margin places footnotes beside the text. Omit that line for the normal footnote placement.

Stock Bootswatch themes

SmallDocs bundles all 25 Bootswatch themes. Use the theme's lowercase name without an extension install:

theme: zephyr

The gallery keeps these styles unchanged. Each stock theme has one original Bootswatch palette. You can pair a light theme such as Zephyr with a dark theme such as Darkly:

theme:
  light: zephyr
  dark: darkly
