Install / update / choose a version / 11 November 2026

Use the current themes.

Install a SmallDocs theme for a new site or update the copy in an existing site. SmallDocs is a website generator. The instructions use Atelier as an example. The table lists all nine themes we maintain.

Use the same theme names when you update. The nine themes we maintain include named design settings and light and dark styles. Prose is 18 to 20px, and code is 16px, larger than in the earlier versions. Existing sites keep their installed copy until you update it.

The three color repairs on 11 November affect Pulse Reading's dark secondary action, Litera Reading's selected navigation, and Darkly Reading's light syntax colors. Prose leading, the distance between lines relative to text size, remains 1.60. Inspect the before/after evidence.

Install or update Atelier

Before using --force, move any edits from the installed extension into your own site stylesheet. The update replaces the installed extension. Run these commands in the folder that holds your _smalldocs.yml:

smalldocs add rahuldave/smalldocs-atelier --force
smalldocs render

For a first install, --force is optional. Keep the same configuration name:

theme: atelier

The command replaces _extensions/atelier/. Before you update, keep local changes in your own stylesheet. Commit the installed extension with your site. smalldocs themes shows its source and commit.

Install the color repairs

Pulse Reading, Litera Reading, and Darkly Reading publish their repaired light and dark modes as v0.2.1. Pin a release, or use the exact source commit listed below:

smalldocs add rahuldave/smalldocs-pulse-reading@v0.2.1 --force
smalldocs add rahuldave/smalldocs-litera-reading@v0.2.1 --force
smalldocs add rahuldave/smalldocs-darkly-reading@v0.2.1 --force

One theme includes both modes

All nine themes that we maintain include light and dark styles, including each Reading extension and Tufte. SmallDocs shows a mode toggle on a site with a navbar or sidebar:

smalldocs add rahuldave/smalldocs-litera-reading
theme: litera-reading

Use theme: litera for the unchanged bundled Bootswatch or litera-reading for our version with both modes. We designed the companion palettes for these extensions. They are not upstream Bootswatch palettes.

To use a different theme for each mode, configure both themes:

theme:
  light: litera-reading
  dark: darkly-reading

Before you use that mixed configuration, install both extensions. A mixed pair is optional.

Install the exact audited revision

An untagged command gets the current default branch. A full commit hash selects an exact source revision. To install the Folio revision assessed here:

smalldocs add rahuldave/smalldocs-folio@e33e059ff40fd49aad28a8b7449cf77449e66898 --force

Use a current SmallDocs installer that supports full commit hashes, such as 0.5.5. If an older installer rejects a full hash, update the SmallDocs package with pip before installing an audited revision. Commit the installed extension so future builds use the same bytes. Keep or restore the earlier versions

The custom v0.2.0 tags preserve the October reading refinement and its earlier title labels:

smalldocs add rahuldave/smalldocs-atelier@v0.2.0 --force

The first custom designs are preserved separately:

smalldocs add rahuldave/smalldocs-atelier@before-reading-redesign-2026-10-16 --force
smalldocs render

The name remains atelier in both cases. For other October sources, use the exact commit in the archived provenance. The October reports and screenshots remain unchanged. The gallery compares current builds with named design settings, original custom snapshots, and unchanged stock themes.

With Quarto

quarto add rahuldave/smalldocs-atelier
format: atelier-html

Replace atelier with any of the nine theme IDs. The Reading formats use Quarto's native Bootswatch base, their own overlay for both modes, and separate font resources. SmallDocs uses the complete compiled CSS. A SmallDocs installation needs no Sass compiler.

Customize the theme's design settings

The handbook explains the foundation file, which names each theme's design settings. It covers reference type sizes, optional display and title-label effects, and an optional local preset for tighter line spacing. Keep variations in a site stylesheet so an extension update preserves them.

Reading profiles set document sizes. Applications can use separate presentation profiles without enlarging document navigation.
