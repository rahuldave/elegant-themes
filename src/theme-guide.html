Use the foundation contract

The authoritative file is src/foundations.json in each theme source. An identical foundations.json ships in its installed extension. It defines named swatches, semantic color roles, paired modes, available font weights, typography profiles, spacing, and shape. Edit the source and rebuild when developing a theme; do not edit generated CSS or compatibility aliases by hand.

The reference root is 16px. Sizes emit rem units and follow browser text preferences. Reading titles are 36px, sections 30px, and the optional display role is 48px. Code and controls use their own roles. The presentation profile is a separate downstream contract; it does not scale the document navigation.

The explicit type and spacing ladders

The foundation type scale is 12, 14, 16, 18, 20, 24, 30, 36, 48, 60, 72. Profiles assign selected steps to prose, interface text, metadata, code and headings. The three custom themes expose every step as a CSS variable, such as --f-size-20: 1.25rem, alongside reading-role variables. Tufte and the Reading themes emit named role variables from the same manifest vocabulary, such as --r-size-body and --r-size-ui. These role values are generated from the manifest; edit and rebuild the source to change the contract.

The spacing scale is 0, 4, 8, 12, 16, 24, 32, 48, 64, 96, 128. It assigns jobs to related items, paragraph gaps, groups, panels and page gutters. Earlier October CSS combined Bootstrap defaults and individual rem, clamp and heading overrides. The November foundations make these shared ladders and reading/presentation profiles explicit.

Reading density is a local choice

The current 1.60 prose leading is more open than Butterick's 1.20–1.45 preferred range. The fixed scorecard records that deduction. If your document reads better with tighter prose, put this optional override in your own stylesheet and inspect both modes:

html:root, html.quarto-dark:root {
  --f-line-reading: 1.45;  /* Folio, Atelier, Nocturne */
  --r-line-reading: 1.45;  /* Reading themes */
  --tf-line-reading: 1.45; /* Tufte */
}

This changes reading leading, not code or control sizes. It is a site-specific variation from the audited defaults; rerun your review after applying it.

Check the rendered component

The palette contracts reserve 5:1 for ordinary text, 4.5:1 for action ink, and 3:1 for meaningful boundaries. They do not override every possible Bootstrap selector. The 11 November follow-up repairs Pulse Reading's dark secondary action, Litera Reading's selected navigation pill, and Darkly Reading's weak light syntax colors; prose leading remains 1.60. Read the before/after measurements and remaining scope limits. Use state words and icons, native disabled behavior, aria-current or aria-selected, and associated error text as appropriate. Color alone does not supply those semantics.

Quarto formats

Install with quarto add rahuldave/smalldocs-NAME and choose format: NAME-html, replacing NAME with the theme ID. Reading overlays compile with Quarto's native Bootswatch base and separate font resources. They do not inject the complete SmallDocs Bootstrap bundle into Quarto. Source repositories include fresh consumer fixtures and build instructions.

Your own stylesheet

Keep custom rules in a file named styles.css in your site folder. SmallDocs loads that file after the theme. Theme updates can then replace _extensions/ without replacing your rules.

In _smalldocs.yml, add the stylesheet beside the theme setting:

theme: atelier
css: styles.css

If you already have stylesheets in css:, add styles.css to that list. In a _quarto.yml built by SmallDocs, put css: under format.html and theme: under smalldocs::

format:
  html:
    css: styles.css
smalldocs:
  theme: atelier

For Quarto itself, add the file to the custom format. Replace atelier-html with folio-html or nocturne-html for those themes:

format:
  atelier-html:
    toc: true
    css: styles.css

Each label recipe adds decorative text above every page title. Change the quoted text to suit your site. Remove the rule to turn the effect off.

For information that changes with the page, use page content or a subtitle: in its front matter. A subtitle appears below the title and remains real page text. Keep essential information out of CSS-generated labels.

Folio

Cream paper and forest green in light mode; deep green and warm pale text in dark mode. Source Serif 4 sets prose and ordinary headings. Libre Caslon Display is an optional 48px display role; DM Sans sets navigation. Code uses IBM Plex Mono.

Configuration: folio. Light and dark modes. SmallDocs and Quarto. Fonts are bundled locally.

smalldocs add rahuldave/smalldocs-folio
theme: folio

The reading refinement uses a 640px prose column and 1.60 line spacing, with 16px code. Folio keeps a fine rule beneath the title block.

The Reading themes

Each Reading extension now includes an explicit light and dark pair. The native palette keeps its Bootswatch anchors; the companion is our authored adaptation. Prose has a 640px measure and 1.60 leading. Code uses local IBM Plex Mono at 16px. State colors have their own roles; a brand accent is not automatically an error color.

Install an extension with its repository name, then set the shorter name in theme:. All nine owned themes support SmallDocs and Quarto. Their manifests define reading and presentation profiles. The document styles use the reading profile.

Pair light and dark themes

All nine owned themes include both modes under one configuration name. SmallDocs shows a mode toggle on a site with a navbar or sidebar.

For Litera Reading alone, use theme: litera-reading to get its complete pair. You can still choose different families for each mode. For example, install Litera Reading and Darkly Reading:

smalldocs add rahuldave/smalldocs-litera-reading
smalldocs add rahuldave/smalldocs-darkly-reading
theme:
  light: litera-reading
  dark: darkly-reading

The first visit follows the browser’s color preference. The mode toggle saves the reader’s choice. The ?mode=light and ?mode=dark controls in the gallery are preview tools.

Tufte

The original point of departure for this collection uses ET Book, cream paper, italic headings, and a narrow reading column. The extension includes light and dark modes for SmallDocs and Quarto.

smalldocs add rahuldave/smalldocs-tufte
theme: tufte
reference-location: margin

reference-location: margin places footnotes beside the text. Omit that line for the normal footnote placement.

Stock Bootswatch themes

SmallDocs bundles all 25 Bootswatch themes. Use the theme’s lowercase name without installing an extension:

theme: zephyr

The gallery keeps these styles unchanged. Each stock theme has one native palette. You can pair a light theme such as Zephyr with a dark theme such as Darkly:

theme:
  light: zephyr
  dark: darkly
