Your own stylesheet

Keep custom rules in a file named styles.css in your site folder. SmallDocs loads that file after the theme. Theme updates can then replace _extensions/ without replacing your rules.

In _smalldocs.yml, add the stylesheet beside the theme setting:

theme: atelier
css: styles.css

If you already have stylesheets in css:, add styles.css to that list. In a _quarto.yml built by SmallDocs, put css: under format.html and theme: under smalldocs::

format:
  html:
    css: styles.css
smalldocs:
  theme: atelier

For Quarto itself, add the file to the custom format. Replace atelier-html with folio-html or nocturne-html for those themes:

format:
  atelier-html:
    toc: true
    css: styles.css

Each label recipe adds decorative text above every page title. Change the quoted text to suit your site. Remove the rule to turn the effect off.

For information that changes with the page, use page content or a subtitle: in its front matter. A subtitle appears below the title and remains real page text. Keep essential information out of CSS-generated labels.

Folio

Cream paper and forest green in light mode; deep green and warm pale text in dark mode. Libre Caslon Display sets the headings, Source Serif 4 sets the prose, and DM Sans sets navigation. Code uses IBM Plex Mono.

Configuration: folio. Light and dark modes. SmallDocs and Quarto. Fonts are bundled locally.

smalldocs add rahuldave/smalldocs-folio
theme: folio

The reading refinement uses a 640px prose column and 1.45 line spacing. Folio keeps a fine rule beneath the title block.

Restore the optional “Field notes” label

Add this rule to styles.css after connecting your stylesheet. It uses Folio’s secondary color in each mode.

html .quarto-title::before {
  content: "FIELD NOTES / SMALLDOCS";
  display: block;
  font: 500 .6rem var(--bs-font-sans-serif);
  letter-spacing: .16em;
  color: var(--e-secondary);
  margin-bottom: 1.3rem;
}

Atelier

Chalk white, deep teal, and DM Sans for headings and prose. The dark palette keeps the same restrained character. IBM Plex Mono sets code.

Configuration: atelier. Light and dark modes. SmallDocs and Quarto. Fonts are bundled locally.

smalldocs add rahuldave/smalldocs-atelier
theme: atelier

The reading refinement uses a 640px prose column and 1.45 line spacing. A fine vertical rule marks the reading column on larger screens. Code blocks have a teal edge.

  display: block;

Nocturne

Pearl paper in light mode; midnight ink and warm brass in dark mode. Source Serif 4 sets headings and prose, DM Sans sets navigation, and IBM Plex Mono sets code.

Configuration: nocturne. Light and dark modes. SmallDocs and Quarto. Fonts are bundled locally.

smalldocs add rahuldave/smalldocs-nocturne
theme: nocturne

The reading refinement uses a 640px prose column and 1.45 line spacing. The short accent rule below the title remains part of the design.

Restore the optional notebook label

Add this rule to styles.css after connecting your stylesheet. The volume number is text you choose; the theme does not count pages.

html .quarto-title::before {
  content: "THE NOTEBOOK · VOL. 01";
  display: block;
  font: 400 .59rem var(--bs-font-monospace);
  letter-spacing: .14em;
  color: var(--e-accent);
  margin-bottom: 1.5rem;
}

The Reading themes

Each Reading extension keeps one native Bootswatch palette. The shared refinement gives prose a 640px column, 1.45 line spacing, smaller headings, and bundled IBM Plex Mono for code. The control colors follow the theme palette.

Install an extension with its repository name, then set the shorter name in theme:. These extensions support SmallDocs. Folio, Atelier, Nocturne, and Tufte also include Quarto formats.

Separate extensions; the bundled Bootswatch themes stay unchanged.

For example, install Litera Reading:

smalldocs add rahuldave/smalldocs-litera-reading
theme: litera-reading

Substitute any configuration name from the table in both places. A name without -reading, such as litera, selects the bundled original.

Pair light and dark themes

Folio, Atelier, Nocturne, and Tufte include both modes under one configuration name. SmallDocs shows a mode toggle on a site with a navbar or sidebar.

For a Reading pair, install a light extension and Darkly Reading:

smalldocs add rahuldave/smalldocs-litera-reading
smalldocs add rahuldave/smalldocs-darkly-reading
theme:
  light: litera-reading
  dark: darkly-reading

The first visit follows the browser’s color preference. The mode toggle saves the reader’s choice. The ?mode=light and ?mode=dark controls in the gallery are preview tools.

Tufte

The original point of departure for this collection uses ET Book, cream paper, italic headings, and a narrow reading column. The extension includes light and dark modes for SmallDocs and Quarto.

smalldocs add rahuldave/smalldocs-tufte
theme: tufte
reference-location: margin

reference-location: margin places footnotes beside the text. Omit that line for the normal footnote placement.

Stock Bootswatch themes

SmallDocs bundles all 25 Bootswatch themes. Use the theme’s lowercase name without installing an extension:

theme: zephyr

The gallery keeps these styles unchanged. Each stock theme has one native palette. You can pair a light theme such as Zephyr with a dark theme such as Darkly:

theme:
  light: zephyr
  dark: darkly
