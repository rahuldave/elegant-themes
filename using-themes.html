Install / update / choose a version

Use a theme in your own site.

The revised Atelier is still atelier. Folio and Nocturne also keep their names. Their reading refinements are version 0.2.0. Existing sites keep their installed copy until you update it. Current default-branch themes omit the fixed title labels; the pinned v0.2.0 release retains them. The theme handbook documents every design and the optional label recipes.

Install the revised Atelier

Run this command in the folder that holds your _smalldocs.yml:

smalldocs add rahuldave/smalldocs-atelier

Set the theme in _smalldocs.yml:

theme: atelier

Render the site:

smalldocs render

Atelier includes light and dark stylesheets, local fonts, and the normal SmallDocs mode toggle. Folio and Nocturne work the same way.

Update an existing Atelier site

Replace the installed theme with the revised release, then render the site:

smalldocs add rahuldave/smalldocs-atelier --force
smalldocs render

Keep theme: atelier. The command replaces _extensions/atelier/. Keep local theme changes in your own stylesheet before replacing that folder.

The untagged command gets the current default branch. Add @v0.2.0 to choose the fixed reading release before the label cleanup.

smalldocs themes shows the installed source and commit. Commit the updated _extensions/atelier/ folder with your site to keep its theme version fixed.

Choose a theme

The repository name goes in smalldocs add. The shorter folder name goes in theme:. The links below open each example site and its source. The theme handbook describes their fonts, modes, and optional effects.

For example, install Litera Reading with:

smalldocs add rahuldave/smalldocs-litera-reading

Then use:

theme: litera-reading

The Reading names are separate from the bundled Bootswatch names. theme: litera selects the stock theme; theme: litera-reading selects our refinement.

Pair a light and a dark Reading theme

The Reading themes keep a single native palette. You can combine two of them. On a site with a navbar or sidebar, SmallDocs adds a mode toggle:

smalldocs add rahuldave/smalldocs-zephyr-reading
smalldocs add rahuldave/smalldocs-darkly-reading
theme:
  light: zephyr-reading
  dark: darkly-reading

Restore the original custom theme

The original Atelier, Folio, and Nocturne are preserved at before-reading-redesign-2026-10-16. To restore the original Atelier:

smalldocs add rahuldave/smalldocs-atelier@before-reading-redesign-2026-10-16 --force
smalldocs render

Keep theme: atelier. Use the untagged command above to return to the current refinement. The comparison view keeps both versions visible on identical pages.

Use the custom themes with Quarto

Folio, Atelier, and Nocturne also include Quarto formats. For Atelier:

quarto add rahuldave/smalldocs-atelier
format:
  atelier-html:
    toc: true

When SmallDocs builds a _quarto.yml project, you can set its theme separately:

smalldocs:
  theme: atelier

Quarto compiles the Sass layers. SmallDocs uses the compiled CSS. The five Reading repositories are SmallDocs extensions.
