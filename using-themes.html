Install / update / choose a version · 10 November 2026

Use the current themes.

The theme names stay the same. The nine owned themes now include explicit paired foundations, larger reading/code roles, and light/dark styles. Existing sites keep their installed copy until you update it. The new analysis flags three component repairs; inspect them before choosing the affected modes or controls.

Install or update Atelier

Run this command in the folder that holds your _smalldocs.yml:

smalldocs add rahuldave/smalldocs-atelier --force
smalldocs render

For a first install, --force is optional. Keep the same configuration name:

theme: atelier

The command replaces _extensions/atelier/. Keep local changes in your own stylesheet before updating. Commit the installed extension with your site. smalldocs themes shows its source and commit.

One theme includes both modes

All nine owned themes now include light and dark styles. This includes each Reading extension and Tufte. SmallDocs shows its normal mode toggle on a site with a navbar or sidebar:

smalldocs add rahuldave/smalldocs-litera-reading
theme: litera-reading

theme: litera still selects the unchanged bundled Bootswatch. litera-reading selects our owned paired adaptation. The companion palettes belong to these extensions, not to upstream Bootswatch.

You can still mix families when you want a different design for each mode:

theme:
  light: litera-reading
  dark: darkly-reading

Install both extensions before using that mixed configuration. A mixed pair is optional.

Install the exact audited revision

An untagged command gets the current default branch. A full commit hash fixes the source exactly. For the Folio revision assessed here:

smalldocs add rahuldave/smalldocs-folio@e33e059ff40fd49aad28a8b7449cf77449e66898 --force

Use a current SmallDocs installer with full-commit support, such as 0.5.5. Commit the installed extension so future builds use the same bytes. The table links each audited revision; use its full hash after @.

Keep or restore the earlier versions

The custom v0.2.0 tags preserve the October reading refinement, including its earlier title labels:

smalldocs add rahuldave/smalldocs-atelier@v0.2.0 --force

The first custom designs are preserved separately:

smalldocs add rahuldave/smalldocs-atelier@before-reading-redesign-2026-10-16 --force
smalldocs render

The name remains atelier in both cases. For other October sources, use the exact commit in the archived provenance. The October reports and screenshots remain unchanged. The gallery's current previews show the new foundation builds alongside original custom snapshots and unchanged stock themes.

With Quarto

quarto add rahuldave/smalldocs-atelier
format: atelier-html

Replace atelier with any of the nine theme IDs. The Reading formats use Quarto's native Bootswatch base plus their own paired overlay and font resources. SmallDocs uses the compiled complete CSS. Installation into SmallDocs needs no Sass compiler.

Customize with the documented roles

The handbook covers the foundation manifest, reference type sizes, optional display and title-label effects, and a denser local reading preset. Keep variations in a site stylesheet so an extension update preserves them. Presentation profiles are separate consumer contracts and do not scale document navigation.
